Welcome to my Spice Coffee Shop webpage where you can:
-View through a list of hot coffee drinks that came from a public api.
-View random art work from the Art Institute of Chicago.
-Share your favorite coffee in a comment box.

Features
-Hot coffe button that fetches and displays a list of hot coffee.
-Random Artwork button that pulls several art pieces from the Art Institute of Chicago.
-User form that allow customers to submit their favorite coffee.

You do not need a live server. Follow these steps below to download and open the webpage:
1. Download the project files**  
   - Either clone the repo or download as a ZIP and unzip it.

2. Open the webpage 
   - Open `index.html` in any modern web browser (Chrome, Firefox, Edge, etc.)

That's it! The webpage will load, and you can interact with the coffee and art features.

API's and Technologies Used:

- [SampleAPIs Coffee API](https://sampleapis.com/api-list/coffee) – for fetching coffee data.
- [Art Institute of Chicago API](https://api.artic.edu/docs/) – for displaying random artwork.


- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- Fetch API
- DOM Manipulation
